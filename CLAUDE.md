This project contains Evolutionary Computation labs.
Each lab solution is stored in corresponding folder at labs folder.
All solutions use the viewer tool.

Provide each solution in python, C, C++ and rust. First python as the baseline. I'll always study the code logic through python.
You are only allowed to use basic python libraries - vanilla code.
Solutions should be simple, only covering given algorithm in its basic form. If you have any interesting idea or improvement in mind that is worth to learn, mention it and we might incorporate it, but the core should stay intact.
Make code human readable and self descriptive, code clarity is the most important factor.
